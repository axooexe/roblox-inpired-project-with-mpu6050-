# roblox-inpired-project-with-mpu6050-

Shake the sensor. Get OOF'd.

A tiny project where an MPU6050 + Arduino Uno detects a hard movement and makes my laptop play the Roblox OOF sound.

Hardware:
components:
Arduino Uno 
MPU6050 
USB connection 

MPU6050 → Arduino Uno (wiring)

VCC	---> 5V
GND	---> GND
SDA	---> A4
SCL	---> A5

Software:

Arduino
PlatformIO — Development and build environment.
Adafruit MPU6050 — Interface library for the MPU6050.
Adafruit Unified Sensor — Sensor abstraction layer used by the Adafruit MPU6050 library.
Wire — I²C communication between the Arduino and MPU6050.
